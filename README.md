# secure-vault-cli 🔐

> Zero-dependency terminal utility to seal and unseal `.env` secrets with AES-256-GCM.

## Usage
```bash
npx secure-vault-cli encrypt .env.production
npx secure-vault-cli decrypt .env.production.vault
```
